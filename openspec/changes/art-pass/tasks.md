# Tasks

Every group is test-first where the behaviour is testable: write the listed tests, watch them fail for the right reason, then build until they pass. Art is rough first and refinable; the checks, not taste, decide when a piece is in. Every group ends with these commands passing (run the import twice on a fresh checkout so `class_name` types resolve):

- `godot --headless --path game --import`
- `godot --headless --path game -s res://tests/smoke.gd`
- `godot --headless --path game -s res://addons/gut/gut_cmdln.gd -gexit`

and with two hand checks: a **1-player check** (solo, offline, from the title, no port opened) and a **host-plus-client check** (a host and a client as two local processes through the shell, title → lobby → run, zero error lines in either log). Captures go in `docs/art-pass/` at 640×360 ×2 and ×3, in *Nítido* and *Suave*.
