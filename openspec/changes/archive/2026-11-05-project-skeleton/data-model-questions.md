# Data model: open questions

Found while deriving the content classes for `project-skeleton` from `docs/` and `openspec/specs/` (one reader per content group, then a reconciler that spot-checked entries against the docs). The classes take the choice named in each item, so they compile and content can be entered, but these are design decisions for the owner of the docs. Settle them before the matching content batch (`TASKS.md` section 10); none of them changes the skeleton itself.

## Contradictions and gaps in the docs

1. **Model / validation (resolved in this change).** Ids inside embedded values (conditions, effects, spawn rules, counters, quests) were not checked. Now every embedded value extends `DataPart`, whose `get_reference_fields()` may depend on its kind, and `ContentValidator` recurses into `DataPart` values and arrays at any depth, naming the path (`parts[1].children[0].item`). This is how the existing content-data requirement "every referenced id SHALL exist" is enforced, so no spec change was needed.
2. **Id spaces without a folder.** Several id spaces have no content folder: quest ids (embedded in NpcData, proposed '<npc_id>_<quest>'), run and profile flags, dialogue states and slots, companion-status ids, unknown-plant look ids (fruta_verde) and minigame ids (polaris). Needed: a validator rule such as 'every FLAG_SET read is set by some SET_FLAG or ChainData.flags_on_enter', and a declared look pool. The spec lists only these flags: 'ramon_photo, caridad_lamp, yunior_alive, companion_<id>_alive, rodriguez_deal, others_helped|robbed'. The design also uses: rodriguez_remembers, marisol_release_used, vieja_tamed, turtle_nest_robbed, next_island_spotted, caridad_dead, hurricane_passed, miami_fisherman_called, yunior_phone_charged, player_wrote_note, companion_died. The look pool ('fruta roja', 'fruta verde', 'baya morada', 'hongo blanco'…) has no manifest home.
3. **Godot 4.7 check.** Three dictionaries use enum keys: ChainData.biome_weights (Dictionary[DataEnums.Terrain, float]), RecipeData.input_tags (Dictionary[DataEnums.ItemTag, int]) and WeatherData.family_weights (Dictionary[DataEnums.ChainFamily, float]). ConditionData.children is a self-typed Array[ConditionData]. Both must round-trip through .tres and the inspector in 4.7.2. Fallback: Dictionary[StringName, …] keyed by enum names, validated against DataEnums.X.keys(). Every enum is serialized as an int, so all enums are append-only.
4. **Chain family as an enum.** DataEnums.ChainFamily is an enum, while variant ids stay StringName references to chains/. The task asked for 'chain ids' as a shared enum; a reviewer suggested StringName so that adding a chain never edits a script. A new family needs a new LayoutRule painter in code anyway. ISLANDS also lists 'Islands 6–7 (far) | Storm key, Shipwreck reef, Bahamas family' as three far chains, although 'the family' is the storm_family variant. Confirm 9 families.
5. **Manifest counts.** 'game/resources/creatures/ (35 + 5 bosses)' and '40 creatures' do not match the 37 listed ids. BESTIARY 'Density check: 35 creature types, 5 bosses' already counts 3 bosses inside the 35. The ITEMS heading says 'Tools (14)', but the table has 16 rows ('16 tools' in Counts). POIs '(~45)' becomes about 57 once the variant signatures are added (fishermen_houses, rusted_well, village_dock, half_sunk_ferry, flooded_quarry, keepers_house_dark, broken_well, resort_hotel, resort_pool, resort_generator, yacht_graveyard, the_buoy). The 'Scattered landing' row ('Players start 10–20 tiles apart') is modelled as ChainData.spawn_scatter_tiles, not a POI file.
6. **Content the docs use but the manifest lacks.** Items: rock ('jug + tarp + rocks', 'rock + knife', 'a knife or a rock'); stick ('tarp + 4 sticks', 'rope + stick', 'Push it away with a stick'); casuarina sap; bandage ('Bandages', 'aloe + bandage'); a fuel/kerosene jug ('bring 2 fuel jugs', 'oars or fuel', 'generator (fuel!)'); conch horn; raw hutía and iguana ('food 25 if caught'); lionfish meat ('food 25'); turtle eggs; beer; pot; feathers; outboard motor; a seep/brackish/pool water cup; carta_caridad ('if Caridad's letter is in your inventory'); the son's photo; the uncle's watch; notebook, pencil and guitar (starting items); torch; boots. Routes: ramons_boat, rowboat ('needs oars'), family_boat, patrol_dinghy ('Steal it (escape route ...)'), smugglers_boat. Creatures: bats (limestone cave). Each needs a manifest line or an explicit substitute, for example driftwood as sticks.
7. **Boss proxies.** The manifest puts boss_hurricane and boss_straits in creatures/ ('boss_hurricane (weather) · boss_straits (crossing script)'), but creatures-ai says 'The hurricane and the Straits are weather bosses in weather-daynight and crossing.' Chosen: proxy CreatureData entries with boss_kind WEATHER (boss_weather_id=hurricane) or CROSSING. The Straits' mechanics are ChainData final_* crossing_events, so no 'crossing script' resource exists. Confirm.
8. **Recipe semantics and numbers.** Non-item outputs are named by the recipe id. Undecided: is raft_hardwood a separate build (integrity 150) or an upgrade ('stronger raft (+50 integrity)')? Are mast and sail upgrades or items ('sail (tarp + mast + rope)')? Does oars output shovel_oar, and does only Papo craft it? Is the knife consumed in flint_steel ('rock + knife')? Is a shovel required for shade_pit or just faster ('Dig in with hands or oars')? GAME_DESIGN's 'mirror signal (any mirror)' recipe is not in the manifest and is modelled as a mirror use. Missing numbers: work times for all 18, counts for hardwood, rope, cloth and raft_repair, and all of signal_fire's inputs. There are no cooking recipes ('Crab (cooked) | Fire + raw crab'), so ItemData.cooks_into was chosen.
9. **Keepsake unlocks contradict.** Pelota: ITEMS 'unlocks if Yunior reaches land' vs CHARACTERS Yusnavy 'if he reaches land, the Pelota firmada keepsake unlocks', and it is missing from §14. Nudo: §14 'Cross 3 times by raft' vs CHARACTERS 'Reward: the Nudo del pescador keepsake unlock'. Medalla: §14 'Save La Vieja's quest' (which quest?) vs 'If a Maestro is in the party, she gives the Medalla', which could be a profile unlock or an in-run GIVE_ITEM. §13 Devuelto 'Unlocks a keepsake' and 'Winning a run ... unlocks a keepsake' name none. Do daily runs count as seeded for 'Seeded runs do not unlock keepsakes'?
10. **Keepsake effects.** Medalla 'One free revive': modelled as the holder standing up at 30 health instead of going down; does it save solo players? Foto 'Morale drain −30%': continuous drains only, or one-off hits too, given 'Morale is shared'? Nudo 'Rafts +25% integrity': does it apply to the 200 boat, and do two holders stack? Cassette '(radio + battery needed)': does the solar charger count? 'Los Van Van' is a real band, against CLAUDE.md 'No copyrighted characters, logos or real people'. Pelota 'Morale +10 to everyone when thrown' can be farmed, so it needs a limit. Capture vs 'cannot be lost unless the player dies': guardacostas says a lone captive 'respawns on the previous island with no items'.
11. **Identification.** crafting-inventory says 'identification is party-wide and run-scoped', but ITEMS says 'Identifications carry over between runs (Experiencia)', and endings-progression persists 'all plant identifications'. Manchineel: ITEMS 'Each run assigns a random look' vs BESTIARY 'unidentified "fruta verde"' (ItemData.fixed_unknown_look). Duplicates: food coco_plum and plant hicaco are both '+8, thirst +3'. Sábila and noni are unknown plants, yet the Médico 'Starts with ... aloe' and ISLANDS names 'Dune with aloe'.
12. **Heat direction (decided 2026-11-05: heat rises to sunstroke at 100; drains retuned in survival-meters).** GAME_DESIGN §4 'Heat | 100 (cool) → 0' vs survival-meters 'Heat SHALL rise 2/min ... At 100, sunstroke'. ModifierData.HEAT_GAIN is defined as a rate toward sunstroke so it works either way, but the meter needs one convention.
13. **Binoculars in calm.** §5 'clear horizon (binoculars work)' vs ITEMS sunglasses 'Binoculars work in scorching calm glare'. This decides calm.binoculars = CLEAR or GLARE, and whether heat_dome ('Three days of scorching calm') inherits the same value.
14. **Fog and sharks.** §5 'sharks hunt by smell (blood matters more)' vs BESTIARY 'sharks hunt by blood only'. Fog has disabled_senses=[SIGHT]. 'Blood only' would also need HEARING disabled (sharks investigate splashes), which would also mute patrol noise alerts in fog.
15. **Tides and the man o' war.** BESTIARY 'beaches at high tide; lies in shallows at low tide' vs weather spec 'Low tide ... strands the man o' war' and §5 'Low tide exposes ... the man o' war'.
16. **Tiger shark and cutter placement.** Tiger: §9 'the tiger shark (reef)' and crossing 'tiger shark (reef only)'; ISLANDS reef says 'the tiger shark on the shipwreck variant', which does not exist, and shipwreck says 'The tiger shark (boss)'. Cutter: BESTIARY 'The first crossing is a chase' (sandbar) vs ISLANDS coast 'the cutter on the crossing out'. These decide ChainData.boss_id and boss_stage.
17. **Patrol numbers.** Coast lore says 'the patrol passes twice an hour', but guardacostas says '3-minute period'. 'Mid chains SHALL spawn patrols at 30% of coast rate' is modelled as spawn chance 0.3; the alternative is frequency. For 'patrols +1 per 2 players', is that per 2 total or per 2 extra players? Jet ski: 'spots swimmers in open water by day', but the consequence and radius are unspecified.
18. **Squall and noon.** Crossing 'Squalls −30' vs BESTIARY 'Raft −30% integrity' (these differ for the 200 boat). §5 calm 'Heat ×2' vs BESTIARY 'Scorching noon | Heat ×2 for 2 hours in-game' vs survival-meters heat rising 'between in-game 10:00 and 16:00'. Scorching noon and 'Rip current (reef shallows)' are not weather manifest entries; the rip current is modelled as EnvHazard RIP_CURRENT on reef_flats.
19. **Dominoes.** ITEMS 'morale +20 for all, costs 1 night phase' vs set piece 'a full night of play restores morale to 100 for all, costs the night'. Does the set piece override the item?
20. **Signal timing.** ITEMS mirror 'Signal boats by day' vs escape-routes 'signal-boat SHALL only succeed in the first hour after dusk or the last before dawn'. The mirror's notice odds are undocumented; the flare's are '100% boats notice, 100% patrols notice'. The 30 s in-game hour is derived from 24 h per 12-minute day.
21. **Expired medicine.** '50% heals 30, 50% nothing, 10% poison' sums to 110%. It is modelled as an exclusive 50/50 roll plus an independent 10% poison roll. 'A Médico reads the label': does that guarantee the heal or only remove the poison, and does it need the user or anyone in the party?
22. **Status definitions.** Bleeding is never quantified ('25 damage + bleeding'). Burning is defined only under fire ants ('burning 10 s (3 damage/s, speed −30%)'), so guao's 'burning 20 s' would deal 60 damage. 'Sunburn' is never defined. 'antidote = aloe + noni': both items, or either? The aloe cures ('Aloe cures' ants, 'reduces the debuff to 10 s') are modelled only as sábila CURE_STATUS and CAP_STATUS. The only documented poison profile is raw crab and fish '(−20 health over 30 s)'; it is assumed for canned food, expired medicine and red tide.
23. **Red tide.** 'Fish and oysters are 60% poison for two days': does that include cooked fish, lobster and conch? Does the Pescador exemption still apply? When do the two days start? Is '1 in 5 runs' rolled per run or per reef visit? The rule is modelled as item EAT effects gated by WEATHER_IS red_tide.
24. **Swimmer energy.** §4 'Swimming 3/s' with '100 energy' gives about 33 s, but crossings are '60–120 second' long, so binoculars_swim and dolphins swimmers collapse. RouteData.swim_drain_multiplier exists but needs a value, or swim crossings must be shorter.
25. **Run and band structure.** ISLANDS gives 'Islands 3–5 (mid)', 'Islands 6–7 (far)', 'Island 8 (final)', but runs are 6–8 islands, so a 6-island run never rolls a far chain. Crossing threats roll from 'its distance band': the departing or the arriving island's? The design uses the departing chain. Carry-over 'escape routes used (per chain)' and 'POI map knowledge for chains reached': keyed by family or by variant? The design assumes family.
26. **Variants that lose their anchors.** Variants 'share the chain's POI table', but: mangrove_river has 'a half-sunk ferry' and no repairable skiff (no repair_wreck, no old-croc nest); reef_bluehole has 'no cave' (no binoculars_swim anchor); storm_resort has no family ('NPC warns a day ahead' and family-house shelter are missing); lighthouse_dark has 'Caridad has died this run' (who supplies the Gulf Stream 'charts + compass from Caridad'?); wreck_yachts has no engine room; final_buoy has 'no land at all' and no route. Also: is lighthouse_dark a weighted roll, or forced because Caridad died earlier ('once per run')?
27. **Npc spawn chances.** NpcSpawnRuleData owns the chances, as the spec says 'spawn rules (chains, chance, min island)'. The docs conflict: Ramón 'Found on: any island' vs 'Ramón's cove | 40%' vs 'signal the fishing boat (Ramón, 30%)'; Papo 'Found alone on a wreck island' vs storm key 'Papo's wreck | 50%'; Marisol 'Found on a sandbar' (island 1 or the final sandbar?). Marisol, Alfredo, Yusnavy, Tania, Tomás, Yunior, the minor NPCs and Vieja's reappearance have no chance at all. 'rolled from chains not yet used for a companion' needs a run budget rule. Coast lagoon 'Crocodile 20% on mid chains only' implies POIs are shared across chain tables.
28. **Ai roster.** §11 names 7 AI NPCs, CHARACTERS marks all 8 companions '— AI', and the manifest says '(12)' profiles. TASKS §8 says 'NPC profiles for the 7 important NPCs' and 'text profiles for the 4 important texts', but ITEMS marks bottle_note and reply_bottle as AI too. No text-profile path is given (texts/<id>.md assumed). Does 'max 240 characters per line' apply to AI letters and diaries? The 'emotion from a fixed set' is never listed (DataEnums.Emotion proposed).
29. **Dialogue files.** The manifest lists 'minor NPC lines (8 files)', but CLAUDE.md requires 'Always ship handwritten fallback lines for offline play' for the 12 AI NPCs, and survival-meters' 'fake voice lines' need a home: proposed <npc_id>.tres and hallucinations.tres. 'Death one-liners (20)' has no list of causes (creature ids plus meter causes?). la_captura is a handwritten beat, yet Rodríguez is 'AI (as antagonist)', and 'A persuasive player ... can talk him into' reads like a choice while guardacostas describes an automatic check.
30. **Companion mechanics.** The spec's 'own meters (simplified: thirst, health)' conflicts with Yunior 'eats half rations' and Papo 'Morale crashes if the flask is empty' (whose morale? is the flask rum?). How do companions without a stated trigger join (only Yunior 'feeds him first' and Vieja have one)? Yunior 'small enough to ride the turtle with one adult' with seats=0: or should he raise the turtle to 3? 'todos (all met companions and NPC allies alive)': does Tomás staying on the sandbar, or Caridad, break Todos? Is El ahogado Yunior's uncle ('The uncle's body is on a later island' vs 'Yunior's uncle's watch')?
31. **Skills and backgrounds.** BESTIARY tiger 'Combat ≥2' and §10 Ex-militar 'Stealth and combat' vs §14's six skills '(fishing, building, medicine, navigation, morale, stealth)'; Skill.COMBAT was added. Unquantified: Médico 'better healing', Maestro 'finds texts' and 'spots islands', Ex-militar 'quieter, hits harder', Dayana '+health per night', El Chino 'patrols take longer to spot', Marisol 'every NPC softens', Ramón 'softens faster', the starting skill level and XP curve (no SkillData). Ex-militar start: §10 'Machete' vs ITEMS 'Military belt | Ex-militar start'. Should background name_en be translated ('Fisherman') or keep the Spanish?
32. **Speed stacking and meal rules.** Do 'A Mecánico builds at 2×', Papo 'twice as fast' and pliers 'building ×1.5' multiply? survival-meters gives '+10 per meal': does a coconut (DRINK, tagged water and food) count? 'Giving water (any cup) revives': seawater, coco and rum too? Repeatable morale (baseball catch +5, fire_pages reading +5, pelota +10) can be farmed: ONCE_PER_DAY limits are proposed.
33. **Shiny and carry rules.** BESTIARY 'carrying a shiny item (mirror, knife out, watch, foil)' vs 'Sheathe shiny items before swimming': carried, or held/equipped only? Is a drawn knife or machete SHINY (ITEMS does not tag it)? Stack sizes and weights are undocumented except 'Heavy (10)'. Are 'Oysters (6)', 'Bird eggs (5)' and 'Flare (×2)' stacks, servings or pickup counts? 'drops a random heavy item at energy 0' needs a threshold.
34. **Resource double-counting.** The resource rules give 'Driftwood | 8' and 'Coconuts | 10 (sandbar/coast), 0 (rock, storm)' per island, while POIs give 'Coconuts, 8–12', 'Driftwood ×10' and 'driftwood ×6, that's it'. Base or extra? Unit mismatches: 'Eggs ×40' vs BESTIARY '10 eggs per nest' vs the item 'Bird eggs (5)'; oysters '10 per cluster' vs 'Oysters (6)'.
35. **Set-piece terms.** Is 'Coast' (patrol_dinghy, patrol_stops) the coast family or the coast band? Is 'Any camp' (dominoes) an NPC camp or the party's fire? 'rare' (wedding) has no number, and no per-island set-piece chance is given. Radio contest: 'the VHF is the only way', but the VHF works 'far chains only' and the rock key is mid; the prize is undefined. Also missing: others_fire outcomes, el_apagon fix requirements, patrol_stops loot, cooler food counts, the bale's rob/trade odds, and wreck_field, ferry and fishermen_houses loot.
36. **Smugglers passage.** 'will carry you for everything you own, or rob you; 50/50' is modelled as CreatureData.offers_route_id -> smugglers_boat (success_chance 0.5, on_start TAKE_ALL_ITEMS). That route is off-manifest, and the destination is undefined.
37. **Hurricane and king tide.** Hurricane: does it happen on every storm-key visit or is it rolled? 'survive the night' (300 s) vs 'water rises 3 tiles over 2 minutes'. Following it with trade wind is inferred from 'the post-hurricane wind is perfect'. Wind direction and exposed damage are not given. King tide 'Sandbar, full moon': no moon cycle exists, so it is approximated as CHANCE per visit; do sealed stashes wash away? Heat dome thirst ×2.5: does it stack with sun ×2?

## Behaviour the data model cannot express

These need code (a system, a generator or a hand-built scene) rather than fields:

- wreck_freighter interior 'a dungeon: decks, holds, ladders': ChainData can name LayoutRule.FREIGHTER and POIs can use WRECK_INTERIOR, but no field describes how decks connect. It needs generator code or a hand-built scene.
- the_funeral 'Their body washes up': it binds to whichever companion died, which is a runtime value, not a static id. It needs a code token or companion-death logic.
- final_buoy 'no land at all; a weather buoy to cling to for one tide': the landmass model has nothing to build on, and no route off is named. Only the VHF channel can be expressed (an interact_effects SET_FLAG on the_buoy).
- family_house 'They offer you to stay. Forever.': an effect can set a flag, but no ending or run outcome consumes it.
- reply_bottle 'a reply to one you wrote on an earlier island (AI)': no note-writing mechanic or storage exists. Data can only gate on a proposed player_wrote_note flag.
- Intro beat 'each player chooses what to grab (one of three items floating by)': the item pool is undefined, and a dynamic choice list cannot be static DialogueData.
- king_tide 'full moon': no lunar cycle exists; approximated as WeatherData.Trigger.CHANCE per island visit.
- Caridad's Polaris mini-game is code. Data only references minigame id polaris and 3 distinct nights.
- Capture and stealth rules that are system code rather than per-entry data: a lone captive respawning 'with no items', hidden states, Stealth '+1 s ... per level', Experiencia 'patrol period +10 s', challenge toggles, and §10 'In solo ... the game is tuned for it'.
- cloth from 'your own shirt (heat +)': no recipe covers it, and RecipeData has no field for crafter penalties.
- fire_pages 'A Bible / a Granma newspaper ... Players choose which they burn first': one manifest id holds a single generic item with 10 page uses.
- Pelican 'Reel fast' depends on fishing-minigame timing (only steal_chance 0.3 is data). Iguana 'at noon when it is sluggish' is finer than DayPhase (approximated as DAY). Hutía 'a Pescador's trap works too' is unclear.
- Croc and old-croc amphibious pathing: domains=[SHALLOW, DEEP, LAND] is declared, but creatures-ai 'Land creatures SHALL use the island AStarGrid2D; sea creatures the water grid' assumes one grid per creature.
- Entries that cannot be valid until missing items or routes exist: recipes solar_still (rock), rain_catcher (stick), snare (stick), flint_steel (rock), resin (casuarina sap), bandage (output); quests caridad_el_queroseno (fuel), caridad_la_carta and rodriguez_el_trato (carta_caridad), ramon_la_foto (photo, fuel); ahogado (watch); Dayana's cure (bandage); starting items for medico, maestro and musico; START_ROUTE targets for Ramón's boat, the rowboat, the family boat, the patrol dinghy and the smugglers' boat.
- Pescador de Miami 'for a fee, a favor, or free': no currency and no defined favor. El turista 'a satellite phone with one bar': no effect. El Chino 'refuses fire at night': no consequence. Marisol 'the credits say the baby's name': no name source. La lista 'adds a line about the previous run's dead': the previous run's dead are not in the carry-over list.
- Cassette 'Músico songs without a Músico': only PLAYS_SONGS and SONG_MORALE are expressed. Músico-only effects ('dolphins come closer', 'a Músico calms them') use PERK_PRESENT or BACKGROUND_PRESENT, and which one applies to the cassette is undefined. Life vest '+buoyancy' is undefined beyond FLOAT_AT_ZERO_ENERGY and swim −20%.

## Found while integrating the classes

- `ConditionData.NPC_STATE_IS` puts the NPC id in `ref_id` but has no field for the state it tests (`EffectData` has `param`; conditions do not). Add a `param` field or a `state` field before NPC state checks are authored.
- `KeepsakeData` and `TextData` inherit `ItemData.category` and `tags`, and a subclass cannot change an inherited default, so every keepsake and text `.tres` must set them; nothing checks this yet.
- `KeepsakeData` unlocks of kind `QUEST_COMPLETED` name a quest, and quest ids have no folder (see item 2), so they are not validated.
- `ConditionData.children` is typed `Array[DataPart]`, not `Array[ConditionData]`: a self-typed array keeps the script alive and Godot 4.7 reports "resources still in use at exit", which fails CI. It still holds only conditions.
- The enum-keyed dictionaries round-trip through `.tres` on 4.7.2 (item 3); whether the inspector edits them well can only be checked in the editor.
